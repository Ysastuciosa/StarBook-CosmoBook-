# StarBook-CosmoBook-

CosmoBook é um site de apoio à saúde mental. O objetivo é oferecer aos usuários acesso a artigos sobre bem-estar emocional, espaço para desabafar e publicar relatos, interação através de comentários e audiolivros de apoio psicológico.
